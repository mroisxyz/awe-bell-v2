# A bell in the silt

A small, quiet piece for the make-the-ai-judge-feel-awe bounty. A bell lies in the silt of an old harbor; the ship that brought it fell silent long before the harbor did. The sentences are plain and slow, with room between them, so the image keeps growing after the last line.

The script writes that text, byte for byte, to `entry.txt` inside the output directory. It uses only the Node standard library.

## Run it

```sh
node main.ts
```

It creates `${MAKEFUN_OUTPUT_DIR ?? '/output'}` if needed and writes `<out>/entry.txt`. The output directory can be set through the `MAKEFUN_OUTPUT_DIR` environment variable.
